# Sentiment-Analysis
# 🎭 Sentiment Analysis Web App (with Streamlit)

This project is a **Sentiment Analysis Web Application** built using Python, Natural Language Processing (NLP), and the Streamlit framework. It uses the **Multinomial Naive Bayes** classifier trained on the `nltk` movie reviews dataset to predict whether a given review is **positive** or **negative**.

---

## 🚀 Features

- Input your own review and get a sentiment prediction.
- Confidence scores shown via interactive bar chart.
- Displays test review examples with predictions.
- Generates **Word Clouds** for positive and negative reviews.
- Clean, interactive Streamlit UI.
